FalkorDB Cloud is the managed service for FalkorDB, the ultra-low-latency graph database. Use the [FalkorDB Cloud console](https://app.falkordb.cloud) or the FalkorDB Cloud API to create instances, change their configuration, take backups, and manage their lifecycle.

<Note>
  The FalkorDB Cloud API is in beta. The endpoints and request/response shapes may change without notice. Contact [support@falkordb.com](mailto:support@falkordb.com) if you have questions or feedback.
</Note>

Every tier includes multi-graph tenancy and graph access control. Higher tiers add TLS, high availability, clustering, automated backups, VPC peering, and dedicated support. See [Features](/features) for the full breakdown.

## Deployment components

Each tier exposes the deployment components it supports:

- **Standalone** — a single node.
- **Single-Zone** (Pro and Enterprise) — a primary with replicas in one availability zone.
- **Multi-Zone** (Pro and Enterprise) — a primary with replicas spread across availability zones.
- **Cluster (Single-Zone)** and **Cluster (Multi-Zone)** (Enterprise) — sharded deployments for larger graphs.

Free and Startup instances are Standalone.

## Set up billing

Paid tiers need a payment method before their instances can run. Add one from **Account Management** > **Payment Settings** in the console. See [Add a payment method](/console/billing).

The Free tier doesn't need billing information.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What cloud providers does FalkorDB support?">
    FalkorDB Cloud is available on **AWS** and **GCP** for the Free, Startup, and Pro tiers. The Enterprise tier adds **Azure**. Enterprise BYOA (bring your own account) runs in your own **AWS** account.
  </Accordion>
  <Accordion title="Can I upgrade my plan later?">
    Yes. On Startup, Pro, and Enterprise you can change an instance's size in place. To move to another tier or deployment type, create a new instance and import your data from the old one. See [Upgrading instances](/operations/upgrading-instances).
  </Accordion>
  <Accordion title="Do I need to set up billing before subscribing?">
    Paid tiers need a payment method before their instances can run. See [Add a payment method](/console/billing). The Free tier doesn't need one.
  </Accordion>
  <Accordion title="What features are available across all tiers?">
    Every tier includes **multi-graph tenancy** and **graph access control**. Higher tiers add TLS, high availability, clustering, automated backups, VPC peering, and dedicated support.
  </Accordion>
  <Accordion title="Is there a free trial available?">
    Yes. The **Free tier** gives you a fully functional graph database instance with 100 MB of RAM on AWS or GCP, with no credit card required.
  </Accordion>
</AccordionGroup>
