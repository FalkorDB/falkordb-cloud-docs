To connect to an instance, you need its **endpoint** (host and port), a **username**, and its **password**. You also need to know whether the instance uses **TLS**.

## Find your connection details

1. In the sidebar, open **Deployments** > **Instances** and select your instance.
2. Open the **Connectivity** tab. The **Primary** endpoint card shows the endpoint as `host:port`. Select the copy icon to copy it.
3. Open the **Instance Details** tab. Under **Parameters**, find the FalkorDB user (by default `falkordb`) and whether TLS is enabled.

{/* SCREENSHOT: images/console/connectivity-tab.png — the Connectivity tab with the Primary endpoint card and the copy icon highlighted */}

{/* SCREENSHOT: images/console/instance-details-parameters.png — the Instance Details tab, Parameters section, showing the FalkorDB user and Enable TLS values */}

The password is the one you set when you created the instance. To use a different user, create one in the [User Access tab](/operations/user-management).

<Note>
  The Connectivity tab appears only while the instance is running. Instances in a **Private** network have no public endpoint. Connect to them from inside your peered network. See [Customer networks](/operations/customer-networks).
</Note>

## Open FalkorDB Browser

FalkorDB Browser is a web UI for running queries and exploring your graphs visually.

1. Wait until the instance status is **Running**.
2. On the instance page, or on the **Instances** list with the instance selected, select **Connect**.
3. FalkorDB Browser opens in a new tab with the host, port, username, and TLS setting filled in. Enter your password and sign in.

{/* SCREENSHOT: images/console/connect-button.png — the instance page with the Connect button highlighted, to the right of the tabs */}

{/* SCREENSHOT: images/console/browser-login-prefilled.png — the FalkorDB Browser login page opened from Connect, with host, port and username filled in and the password empty */}

The **Connect** button is turned off for instances in a **Private** network, because the browser can't reach them.

To learn the Browser itself, see the [FalkorDB Browser guide](https://docs.falkordb.com/browser).

## Connect with redis-cli

Replace the host, port, and password with your own values. Add `--tls` if the instance has TLS enabled.

```bash
redis-cli -h <host> -p <port> --user falkordb --pass "$FALKORDB_PASSWORD" --tls \
  GRAPH.QUERY social "CREATE (:Person {name: 'Alice'}) RETURN 1"
```

## Connect with a client library

Each example connects to a TLS-enabled instance. For an instance without TLS, remove the TLS option.

<CodeGroup>
```python Python
from falkordb import FalkorDB

db = FalkorDB(
    host="<host>",
    port=6379,
    username="falkordb",
    password="<password>",
    ssl=True,
)
graph = db.select_graph("social")
result = graph.query("MATCH (p:Person) RETURN p.name")
print(result.result_set)
```

```javascript Node.js
import { FalkorDB } from "falkordb";

const db = await FalkorDB.connect({
  username: "falkordb",
  password: "<password>",
  socket: { host: "<host>", port: 6379, tls: true },
});
const graph = db.selectGraph("social");
const result = await graph.query("MATCH (p:Person) RETURN p.name");
console.log(result.data);
await db.close();
```
</CodeGroup>

For other languages, see [Client libraries](https://docs.falkordb.com/getting-started/clients).

<Warning>
  Read the password from an environment variable or a secret manager. Don't hardcode it in your code or commit it to source control.
</Warning>

## Troubleshooting

| Problem | What to check |
| :--- | :--- |
| Connection refused or timeout | The instance status is **Running**, and the host and port match the **Connectivity** tab. For Private networks, connect from inside the peered network. |
| TLS or SSL error | Turn on TLS in your client if the instance has **Enable TLS** set, and turn it off if it doesn't. The Free tier has no TLS. |
| Authentication failed | The username and password are correct. Users created in **User Access** need the right role for the commands you run. |
| **Connect** is disabled | The instance isn't running yet, or it's in a **Private** network. |

Still stuck? Email [support@falkordb.com](mailto:support@falkordb.com) with your instance ID.
