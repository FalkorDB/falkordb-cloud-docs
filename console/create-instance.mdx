An instance is a running FalkorDB deployment. It can be a single node or a replicated or clustered setup, depending on the tier. This guide uses the FalkorDB Cloud console. To do the same with the API, see the [Quickstart](/quickstart).

## Before you begin

- [Sign up](/console/sign-up) for a FalkorDB Cloud account.
- For a paid tier, [add a payment method](/console/billing).
- For a private Enterprise deployment, [create a customer network](/operations/customer-networks) first.

## Create the instance

<Steps>
  <Step title="Open the create form">
    In the sidebar, open **Deployments** > **Instances** and select **Create**. The **Create Deployment Instance** form opens.

    {/* SCREENSHOT: images/console/instances-list.png — the Instances page with the toolbar (Stop, Start, Modify, Delete, Connect, Create) */}
  </Step>
  <Step title="Choose a plan">
    Under **Subscription Plan**, choose a tier: **FalkorDB Free**, **FalkorDB Startup**, **FalkorDB Pro**, **FalkorDB Enterprise**, or **FalkorDB Enterprise BYOA**. If you haven't subscribed to the plan yet, select **Subscribe** on its card.

    If you have more than one subscription to the plan, pick one under **Subscription**.

    {/* SCREENSHOT: images/console/create-instance-plan.png — the Standard Information card with the subscription plan cards */}
  </Step>
  <Step title="Choose a deployment type">
    Under **Resource Name**, choose how the instance is deployed. The list shows only the types your tier supports. Free and Startup instances are always Standalone, so the field doesn't appear for them.

    | Deployment type | What you get | Tiers |
    | :--- | :--- | :--- |
    | **Standalone** | A single node | Free, Startup, Pro, Enterprise |
    | **Single-Zone** | A primary and a replica in one availability zone | Pro, Enterprise |
    | **Multi-Zone** | A primary and a replica in different availability zones | Pro, Enterprise |
    | **Cluster-Single-Zone** | A sharded cluster in one availability zone | Enterprise |
    | **Cluster-Multi-Zone** | A sharded cluster across availability zones | Enterprise |

    You can't change the deployment type later. To move to another type, create a new instance and [import your data](/operations/export-import#another-instance).
  </Step>
  <Step title="Choose a cloud provider and region">
    Select the **Cloud Provider** logo (AWS or GCP, plus Azure on Enterprise), then choose a **Region**. Pick the region closest to your application to keep latency low.
  </Step>
  <Step title="Choose the network (Enterprise)">
    If your plan supports private networking, the **Network Configuration** card appears:

    - **Public** gives the instance a public endpoint.
    - **Private** places it in a customer network. Choose the network under **Customer Network ID**.

    See [Customer networks](/operations/customer-networks).
  </Step>
  <Step title="Configure the database">
    Under **Deployment Configuration**, fill in:

    - **Name**: a name to help you find the instance.
    - **Memory** or instance size: how much RAM the instance has. See your tier page for sizes and prices.
    - **FalkorDB user**: the default username. It's set to `falkordb`.
    - **FalkorDB password**: the password for the default user. Use at least 6 characters.
    - **Enable TLS** (Startup and above): encrypts connections to the instance. You can't change this after the instance is created.

    The other settings, such as persistence and FalkorDB tuning options, have sensible defaults. You can leave them as they are.

    {/* SCREENSHOT: images/console/create-instance-config.png — the Deployment Configuration card with name, memory, user, password and Enable TLS fields, and the Deployment Instance Summary panel on the right */}

    <Warning>
      Store the password somewhere safe, such as a password manager. You need it every time you connect.
    </Warning>
  </Step>
  <Step title="Create">
    Check the **Deployment Instance Summary** panel and select **Create**.

    The **Launching Your Instance** dialog shows the new **Instance ID** and its **Lifecycle Status**. Most instances are ready within a few minutes.
  </Step>
</Steps>

## Check the status

Your instance appears in the **Instances** list. Wait until its status is **Running**, then [connect to it](/console/connect).

Select the instance name to open its detail page. The tabs on that page include:

| Tab | What it's for |
| :--- | :--- |
| **Instance Details** | Configuration, FalkorDB version, and parameters such as the username |
| **Connectivity** | The endpoint you connect to. See [Connect to your instance](/console/connect). |
| **Nodes** | Each node's endpoint, zone, and health |
| **User Access** | Extra database users. See [User management](/operations/user-management). |
| **Metrics** | The monitoring dashboard (not on Free). See [Monitoring dashboard](/operations/monitoring-dashboard). |
| **Backups** and **Snapshots** | Automatic backups and restores (Startup and above). See [Backups and snapshots](/operations/backups-snapshots). |
| **Import/Export RDB** | Load or save your data as an RDB file. See [Export and import](/operations/export-import). |

## Change, stop, or delete an instance

From the **Instances** list, select the instance and use the toolbar:

- **Modify** changes the instance size. See [Upgrading instances](/operations/upgrading-instances).
- **Stop** and **Start** pause and resume the instance. A stopped instance is removed after 14 days. See your tier page for details.
- **Delete** removes the instance. Type `deleteme` to confirm. You can choose **Take final snapshot before deletion** to keep a copy of the data.
